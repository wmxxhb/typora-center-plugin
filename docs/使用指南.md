# Typora 1.9.5 居中插件使用指南

本指南对应插件 **1.0.1** 和仓库的 **typora-1.9.5** 分支，适用于 Windows 上的 Typora **1.9.5**。

原先适配 Typora 1.13.4 的版本仍保留在 [main 分支](https://github.com/wmxxhb/typora-center-plugin/tree/main)。两个版本分别保存，下载时请确认分支和安装包名称。

## 下载与准备

1. 下载 [Typora 1.9.5 适配版插件安装包](https://github.com/wmxxhb/typora-center-plugin/raw/refs/heads/typora-1.9.5/dist/typora-center-plugin-1.0.1-typora-1.9.5.zip)，并完整解压。
2. 确认电脑已安装 **Node.js 18 或更高版本**。安装包没有其他依赖，也无需执行 `npm install`。
3. 保存正在编辑的文档，完全退出 Typora。

安装包提供的是居中插件，不包含 Typora 本体。请先自行安装 Typora 1.9.5。

## 安装

在解压后包含 `install.cjs` 的目录打开终端，执行：

```powershell
node install.cjs "D:\APP\Typora\Typora"
```

将路径替换为实际的 Typora 安装目录，该目录应包含 `Typora.exe` 和 `resources` 文件夹。若安装目录需要管理员权限，请以管理员身份打开终端。

看到安装成功提示后，重新启动 Typora 即可使用。

## 居中与取消居中

| 操作 | 方法 |
| --- | --- |
| 当前段落或标题居中 | 将光标放入其中，按 **Ctrl + Alt + E** |
| 使用菜单 | 在正文或标题中右键，选择 **居中 / 取消居中** |
| 多段批量居中 | 选中多个段落或标题，再执行居中 |
| 取消居中 | 在已居中的段落或标题中再次执行 |
| 批量取消 | 选中全部已居中的段落，再执行一次 |
| 撤销 | **Ctrl + Z** |
| 重做 | **Ctrl + Y** |

混合选中已居中和未居中的段落时，会统一设为居中。居中按整段生效，支持普通段落和一级至六级标题，并保留粗体等行内格式。

## 与原版的区别

- **入口**：1.9.5 使用右键菜单，不在顶部“格式”菜单中添加项目。
- **快捷键**：1.9.5 的 **Ctrl + Shift + E** 已被“使用上一次设置导出”占用，因此适配版使用 **Ctrl + Alt + E**。
- **加载方式**：1.9.5 通过 `resources/window.html` 加载插件，保持 `app.asar` 和原生模块 `main.node` 原样。

## 支持范围与注意事项

- 在普通编辑模式下使用。源代码模式、表格、代码块和公式块不适用。
- 保存、关闭再打开文档，居中效果仍会保留。
- Markdown 源码中会加入带居中样式的 HTML 标签，编辑界面会隐藏这些标签。其他编辑器是否显示居中取决于其 HTML 支持。
- 本次验证了 HTML 导出后的居中效果；PDF 导出未单独实测。

## 更新与重新安装

保存文档并退出 Typora，解压更新后的插件安装包，再次执行相同的安装命令即可。

Typora 更新后如果右键入口或快捷键失效，可尝试重新安装；本次仅在 Typora 1.9.5 实测，其他版本需要另行验证。

## 卸载

保存文档并完全退出 Typora，在插件目录执行：

```powershell
node install.cjs "D:\APP\Typora\Typora" --uninstall
```

重新启动 Typora 后生效。卸载会从备份还原原页面，保留文档中的居中样式。

备份和安装记录位于 Typora 安装目录下：

```text
resources/typora-center-original-window.html
resources/typora-center/installation.json
```

如果页面在插件安装后被 Typora 更新或其他工具修改，卸载程序会停止，避免覆盖这些变化。遇到此提示请先检查页面和备份，不要强行替换。

## 常见问题

**找不到 `app.asar`**：检查传入的路径是否为 Typora 安装目录，而不是插件目录或 `resources` 目录。

**找不到居中菜单**：1.9.5 的入口位于正文右键菜单，请保存文档并完全退出 Typora 后重新启动。

**快捷键没有反应**：先在普通段落或标题中放置光标，使用 **Ctrl + Alt + E**；也可用右键菜单确认插件是否加载。

**其他编辑器看到 HTML 标签**：这是保存居中信息所需的文档内容。显示效果由其他编辑器的 HTML 支持决定。
